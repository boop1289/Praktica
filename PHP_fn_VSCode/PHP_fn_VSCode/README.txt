Практическая работа: Стрелочные функции (fn) и анонимные функции PHP.
Откройте эту папку в VS Code (File → Open Folder).
Требуется PHP 7.4 или новее, доступный в PATH. Дополнительные библиотеки не нужны.
В терминале выполните по очереди:
php task1.php
php task2.php
php task3.php
php task4.php
php task5.php
Файлы task*_result.txt содержат фактические результаты проверочного запуска.
Отчёт Word находится в этой же папке. Впишите ФИО перед сдачей.
